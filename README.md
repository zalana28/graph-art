# 🎨 GitHub Contribution Graph Art 2018-2026

Repository ini berisi commits yang membentuk pola angka tahun **2018 hingga 2026** di GitHub contribution graph.

## 📊 Preview

Setiap tahun menampilkan angka tahunnya sendiri:
- **2018**: Pola angka "2018"
- **2019**: Pola angka "2019"
- **2020**: Pola angka "2020"
- **2021**: Pola angka "2021"
- **2022**: Pola angka "2022"
- **2023**: Pola angka "2023"
- **2024**: Pola angka "2024"
- **2025**: Pola angka "2025"
- **2026**: Pola angka "2026"

## 🛠️ Teknis

- **Font**: 3x5 pixels per digit
- **Grid**: 7 baris (Senin-Minggu) × 53 kolom (minggu)
- **Commits per cell**: 10 (untuk warna hijau pekat)
- **Total commits**: ~6800

## 📝 Cara Melihat

1. Buka profile GitHub: https://github.com/zalana28
2. Scroll ke bagian contribution graph
3. Pilih tahun dari dropdown (2018-2026)
4. Lihat pola angka tahun terbentuk!
